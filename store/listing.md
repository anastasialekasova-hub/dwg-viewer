DWG Viewer

## Краткое описание (122/132)

Use DWG Viewer to open a DWG file in Chrome, view DXF online, toggle layers and save the view to PDF. Nothing is uploaded.

## Полное описание — утверждённый вариант (4 765 симв., со строкой GPL)

Need to know how to open DWG file attachments without a CAD program?

DWG Viewer opens DWG and DXF drawings right in a Chrome tab. It works in Chrome 116 or newer on Windows, macOS, Linux and ChromeOS, and the file never leaves your computer.

Open DWG Drawings in Three Steps

Here's how to view DWG files in Chrome, from install to your first drawing.

1. Add the extension and click its toolbar icon.
2. Click "Open file…" or drag a drawing into the tab.
3. Pan, zoom and turn layers off to see just the part you need.

Opening DWG File Links

On supplier pages, portals and forums, you can usually view a DWG file online with a single click.

➤ Click a .DWG or .DXF link, and it opens in a new tab to the right
➤ The "Opened from" bar names the source, and "Download original" saves the file
➤ Turn link opening off in Settings, and right-click "Open in DWG Viewer" still works

Pan, Zoom and Layers

Move around with a mouse or a trackpad.

∙ Drag to pan, scroll or pinch to zoom toward the cursor
∙ Fit or double-click to see the whole drawing again
∙ Tick layers on and off, or use Show all and Hide all
∙ Pick a Dark or Light background, and it's remembered

What It Draws

Here's what you get in model space when you open DWG format files.

📐 Colors and linetypes from the file
📐 Text, dimensions and hatches
📐 A counter like "240 of 250 objects drawn"
📐 A banner naming any object types it skipped

View DXF Files the Same Way

A DXF export from a laser cutter or CNC program is usually a 2D drawing, and it opens here too.

– The same "Open file…" button, drag and drop and link clicks
– The same layers, zoom and background switch
– The same print view, so DXF to PDF works too

Print or Save DWG to PDF

Print sends the on-screen view to Chrome's print dialog: pick a printer or Save as PDF.

▸ Same zoom, position and visible layers
▸ A light background, whatever you use on screen
▸ File name and date on top, layer and object counts below
▸ The PDF is a picture of the view, not an editable vector file

Everyday Cases

A quick look is all most CAD drawings need.

📌 A site plan in a client email: check the layout before you reply
📌 A supplier's parts catalog: open a DWG file online before you order
📌 A work laptop with no CAD program: open DWG drawings and read the dimensions
📌 A meeting in ten minutes: print the view or save it as PDF

Compared with Upload Websites

If you've used a .DWG file viewer online, you know the upload step.

• Privacy: the drawing stays on this computer, not a server
• Links: open DWG online right from the page
• DXF: view DXF online in the same tab
• Accounts: no sign-up, no email, no file history

Tips for Faster Checks

A few habits make viewing DWG files quicker on busy sheets.

✔️ Pin the extension icon so the viewer tab is one click away
✔️ Hide hatch and text layers to read the geometry on a dense plan
✔️ If thin colored lines are hard to see, switch to the light background

What It Doesn't Do

It's built for reading a 2D drawing, not changing it.

✖️ No editing, measuring, 3D or format conversion
✖️ Some file versions won't open; external references and images aren't drawn
✖️ Double-clicking a file in Finder or File Explorer won't open it here
✖️ Google Drive and Dropbox share links usually don't work
✖️ Closing the tab clears the file: no recent list, no cloud

View DWG Online Without Uploading

A typical .DWG viewer online asks you to upload the file first. Here, the status bar reads "Rendered on this computer".

🔒 No account, sign-in or cloud storage
🔒 Nothing about you or your files is collected or sent
🔒 Only your settings and the rating prompt's state are saved, never drawings or links

Chrome warns at install that DWG Viewer can "Read and change all your data on all websites". It needs that to download a drawing you click, with your login on that site, and to handle links in tabs already open. On pages, it reads only the clicked link's address.

Questions and Answers

❓ How to open DXF file exports from a laser cutter app?
👉 Click "Open file…" and pick it, or drag it into the tab.
❓ How to view DWG drawings sent by email?
👉 Save the attachment, then drop it into the tab.
❓ Is there a DWG Viewer for Mac?
👉 Yes. It runs in Chrome on macOS, so you don't need a Windows VM.
❓ Why did a link fail to open?
👉 Some sites keep files behind a login or a share page, so DWG Viewer can't always fetch them. Press "Download instead" and drop the file into the tab.

## Примечание для модератора CWS (Single purpose / Permissions / Remote code)

```
Single purpose: View DWG and DXF drawings in a Chrome tab, from a file on the
computer or from a link to a .dwg or .dxf file that the user clicks.

storage: saves the user's settings (open links here on/off, canvas background)
and the state of the rating prompt.
contextMenus: adds "Open in DWG Viewer" to the right-click menu, only on links
to .dwg and .dxf files.
scripting: after install or update, adds the link handler to tabs that were
already open, so a click on a .dwg or .dxf link works without reloading them.
declarativeNetRequestWithHostAccess: when the user navigates directly to a
.dwg or .dxf address, opens it in the viewer instead of a download.
Host permissions (http://*/*, https://*/*): drawings are linked from any site
(manufacturers, file shares, portals). The content script reads only the address
of the clicked link, and only if it ends in .dwg or .dxf; it does not read or
change page content. The viewer downloads the clicked file from its own site,
with the user's cookies for that site, and renders it on the computer.
Nothing is sent anywhere else.

Remote code: No. All code is in the package, including the WebAssembly DWG
parser (LibreDWG, GPL-3.0); 'wasm-unsafe-eval' is used only to run that
packaged WebAssembly.
Data usage: the extension does not collect or transmit any user data.
```
